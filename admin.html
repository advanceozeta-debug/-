게임 열기

로그인

GitHub 토큰으로 이 저장소에 저장할 수 있는 사람만 설정을 바꿀 수 있어요. 토큰은 이 브라우저에만 저장돼요.

토큰 만드는 법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 게임 저장소 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만든 토큰을 복사해서 위에 붙여넣기

확률·상품

숫자는 비율이에요. 합계가 100이 아니어도 비율대로 나눠 뽑아요. 당첨 상품을 여러 개 넣으면 당첨될 때 그중 하나가 무작위로 나와요.

–당첨 확률

저장하면 1~2분 뒤 게임 사이트에 반영돼요.

뽑기 기록

모든 사람의 뽑기 결과를 내 구글 시트에 모아요. 처음 한 번만 연결하면 돼요.

  1. 새 구글 시트를 만들고, 메뉴에서 확장 프로그램 → Apps Script를 눌러요.
  2. 안에 있는 코드를 모두 지우고 아래 코드를 붙여넣어요. 맨 위 ADMIN_KEY를 나만 아는 비밀번호로 바꾸고 저장(💾)해요.
  3. 오른쪽 위 배포 → 새 배포 → 유형 웹 앱. 다음 사용자로 실행: 나, 액세스 권한: 모든 사용자 → 배포. 권한 허용 창이 뜨면 허용해요.
  4. 나온 웹 앱 URL과 1번에서 정한 비밀번호를 아래에 넣어요.

–전체
–당첨
–실제 당첨률
–오늘

    최근 300번까지 보여요. 전체 기록은 구글 시트의 '기록' 탭에 있어요. 30초마다 자동으로 새로고침돼요.
