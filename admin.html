로그인

GitHub 토큰으로 이 저장소에 저장할 수 있는 사람만 설정을 바꿀 수 있어요. 토큰은 이 브라우저에만 저장돼요.

토큰 만드는 법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 게임 저장소 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만든 토큰을 복사해서 위에 붙여넣기

    게임 기기 연결하기
    1. 게임을 돌릴 기기마다 한 번씩만 하면 돼요.
    2. 아래 QR 보기를 누르고, 게임 기기 카메라로 QR을 찍어 열면 바로 연결돼요. (또는 링크를 복사해서 그 기기 크롬에서 열어요.)
    3. 게임 화면 오른쪽 아래 구석에 작은 초록 점이 보이면 연결된 거예요. 노란 점은 올리는 중, 빨간 점은 인터넷 연결을 확인해 주세요.

    이 QR과 링크는 찍기만 하면 연결되는 열쇠예요. 부스 기기에만 쓰고, 다른 사람에게는 보여주지 마세요.

    카톡 등으로 게임 기기에 보내서 크롬으로 열어도 돼요. 비밀번호 없이는 쓸 수 없어요.
